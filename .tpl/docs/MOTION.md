# 动效清单与差异

参考为公开预览组件，读取其公开加载资源核对参数；浏览器只读到页面结构，截图与后续操作超时后被工具阻止。以下是实现清单，不能当作实际运行验收。

| 导航入场 | y=-40→0、opacity0→1，1.4秒，ease[.16,1,.3,1] |
| 标题 | x=-50→0、opacity0→1；spring stiffness70/damping12；延迟.8秒、词间.18秒 |

差异：原Braah One/Gabarito字体与大字号依项目排版要求改为MiSans/Poppins和28–44px标题；中文标题按语义分行。装饰箭头去除；主入口接真实好物页。新增播放、暂停、重置、错误提示与键盘场景按钮。原参考吞没播放异常的做法未沿用。减少动态效果时禁用入场、跟随、旋转与悬停运动，视频默认暂停，可手动播放。
